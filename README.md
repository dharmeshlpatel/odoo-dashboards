# Odoo Dashboards 19.1 (v2)

## Modules

| Module | Role |
|---|---|
| **`dashboard_engine`** | Dynamic Dashboard Engine — build kanban dashboards for any Odoo model via blueprints. Depends only on `base` + `web` (ordered tags widget is built in). |

All previous host shells, app packs, and report helpers were replaced by soft-dependency blueprints inside `dashboard_engine`.

Publish **`dashboard_engine` only** on the Odoo Apps Store.
